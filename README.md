# oyjon

A calm baby tracker for pregnancy and the first year, Uzbek first. Logs fill a monthly "moon" that becomes a keepsake, and an Uzbek AI assistant answers only from doctor-reviewed cards.

**Start with [`CLAUDE.md`](CLAUDE.md)**, then [`docs/`](docs/README.md).

| Folder | What's in it |
| --- | --- |
| `apps/mobile/` | Expo + React Native + TypeScript app ([`CLAUDE.md`](apps/mobile/CLAUDE.md)) |
| `supabase/` | Backend, from Milestone 3 |
| `content/` | Cards and red-flag rules shared by app and server |
| `docs/` | Spec, roadmap, decisions, open questions, research |
| `design/` | Design work and Figma links |

Run the app and work with Claude Code: [`docs/getting-started.md`](docs/getting-started.md).
